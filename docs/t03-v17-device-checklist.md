- [ ] 初次訪客閱讀、書櫃、位置恢復、已讀標記正常。
- [ ] A 登入後，僅顯示 A 的閱讀進度／捲動位置／已讀標記。
- [ ] 登出 A 後，顯示訪客紀錄，不顯示 A。
- [ ] B 登入後，僅顯示 B；不自動匯入 A 或未知歸屬舊紀錄。
- [ ] B 登出、A 重新登入，A 原有紀錄恢復。
- [ ] 網路中斷／身分不明時，不上傳、不錯誤認領資料。
- [ ] 切換帳號期間，舊請求晚到不覆蓋新會員畫面或進度。
- [ ] 同時開兩個分頁，登出後舊分頁不顯示會員資料。
- [ ] Safari／Chrome 上下頁返回（BFCache）後重新驗證，不恢復錯誤會員。
- [ ] PWA 離線重訪章節，可取得必要 JS；離線時不宣稱雲端同步成功。
