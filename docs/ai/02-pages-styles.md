# 02 頁面、版型與樣式
| 頁面 | 檔案 | 網址 |
|---|---|---|
| 首頁（探索故事書架） | index.html | / |
| 作品頁 | novel/<id>.html → _includes/novel-page.html、novel-post.html | /novel/<id>/ |
| 章節 | _posts/*.md（layout thread） | /t/<slug>/ |
| 角色 | characters.html | /characters/ |
| 臺灣故事 | taiwan.html＋_includes/taiwan-map.html（/novels/ 轉址） | /taiwan/ |
| 互動年代 | era.html＋_includes/era-event.html、era-research.html | /era/ |
| 研究所 | literature.html＋_literature/ | /literature/ |
| 會員 | member.html、shelf.html、favorites.html、my-comments.html | /member/ 等 |
| 管理 | admin.html＋assets/admin.js | /admin/ |
- 樣式：`assets/style.css`（S04 起依功能拆分，見檔頭說明）。斷點：手機 ≤767、平板 768–1023、電腦 ≥1024。
