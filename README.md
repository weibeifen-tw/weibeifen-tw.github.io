## 新增一串貼文

在 `_posts/` 新增一個 `.md` 檔，檔名格式是 `年-月-日-英文名稱.md`，例如 `2026-11-20-first-phone.md`。

內容照這個樣子寫：

```
---
layout: thread
title: 第一支手機
character: mo
novel: yu
teaser: |
  發在動態牆上的那一則：這章的重點或一個細節。

  可以有好幾段，每行前面空兩格。
date: 2026-11-20 22:30:00 +0800
---
整章的內容。

***

（用 *** 隔開的地方，會顯示成分段符號 · · ·）
```

- `teaser` 是動態牆上顯示的那一則，整章內容會出現在角色的個人頁。
- `date` 是貼文顯示的發文時間，可以設成故事裡的任何時間。
- 章節裡想分段的地方，用單獨一行的 `***`。
- 段落之間空一行。

## 排程發章

想讓章節晚點才上線：把章節檔放進 `.github/scheduled/上線日期/`，例如
`.github/scheduled/2026-11-20/2026-11-20-yang11.md`。

每天早上 8 點左右（台灣時間），日期到了的章節會自動搬進 `_posts/`，網站重建後就看得到。
一個資料夾可以放好幾章；想一天發一章，就一天開一個資料夾。

- 檔名和 `date` 照舊是故事裡的時間，但**不能晚於上線那天**，否則上線了也會被藏起來。
- 臨時想提早發：到 GitHub 的 Actions →「排程發章」→ Run workflow（只會發日期已到的）。

## 新增角色

在 `_data/characters.yml` 加一段。頭貼圖檔放進 `assets/avatars/`，再把檔名填在 `avatar:`；沒有圖就刪掉那一行，會顯示 `glyph:` 那個字。

## 新增小說

在 `_data/novels.yml` 加一段，首頁上方就會多一個篩選按鈕。
